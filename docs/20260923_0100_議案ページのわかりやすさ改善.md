# 議案ページのわかりやすさ改善（ことばの説明と予算の図解）

## 背景

令和8年度一般会計補正予算（議案第50号）のページについて「よくまとまっているが単語が難しい。図があったり、もう少し理解しやすい箇所があると助かる」という声があった。予算の議案は「繰越金」「債務負担行為」「財政調整基金」のような専門用語が多く、金額の並びも文章だけでは頭に入りにくい。

## 変更

### 1. むずかしいことばの説明（全議案・委員会記録）

- サイト共通の用語集 `web/src/features/glossary/shared/data/glossary.ts`（約50語）。委員会記録だけで使っていた12語を取り込み、予算・議会手続きの語を足した
- **本文中の初出に点線の下線**を付け、タップで短い説明を出す（`GlossaryTerm`、Popover）。スマホではホバーが使えないため title 属性ではなくポップオーバーにした
  - 印は h2 で区切ったブロックごとに各語1回。読者がどの節から読み始めても近くに説明がある
  - 「財政調整基金」の中の「基金」のように熟語の一部には付けない（漢字のことばの前後に漢字、カタカナ語の前後にカタカナが続けば付けない。「補正予算案」「当初予算額」のように「案・額・等・分・後・前・中」が続く場合は付ける。かなで終わる語の後ろの漢字は普通の文なので付ける）
  - 見出し・リンク・コード・図の中には付けない
- **ページ下部に「この議案に出てくることば」**の一覧（`GlossarySection`）。委員会記録の詳細ページも同じ部品に置き換えた
- 印はページ内で各語1回だけ（当初は h2 ごとに1回にしていたが、印はボタンなので「長押しで選択してAIに質問」がその語では使えなくなる。数を絞り、2回目以降は下部の一覧で読む）。議案第50号は解説の先頭に h2 を足したため、`LongPressSection` の差し込み位置（3つ目の h2 の前）が1節分早まる
- 実装: `web/src/lib/markdown/rehype-glossary-terms.ts`（rehype-sanitize の後段）、`web/src/features/glossary/shared/utils/find-glossary-mark.ts`（純粋関数・テスト付き）

### 2. 予算の図解（解説文に埋め込む）

- 解説文（Markdown）に ```budget-chart のコードブロックで JSON を書くと、棒グラフ（`BudgetChart`）に置き換わる。JSON が読めなければコードブロックのまま残す（書き手が気づける）
- 図の中身: 予算総額の変化（補正前 → 今回の補正 → 補正後）と、歳出・歳入の内訳（増減を棒の長さで、△は減額）。金額は「367億464万5,000円」の読み方で添える
- 実装: `web/src/lib/markdown/rehype-budget-chart.ts`、`web/src/features/bills/shared/utils/budget-chart.ts`（定義の検証と金額の表記・テスト付き）、`web/src/features/bills/server/components/bill-detail/budget-chart.tsx`
- データは `packages/seed/tagawa/bill-descriptions-batch-f.ts` の令和8年9月定例会の補正予算5件（議案第50〜54号）に追加。第50号は歳出・歳入の内訳つき、第51〜54号は総額の変化のみ。数字は議案説明資料（PDF）の値
- 第50号には「## ひとことで言うと」の3行を解説の先頭に足した（事実は既存の解説の範囲内）

## 反映の手順

解説文（`packages/seed/tagawa/bill-descriptions-batch-f.ts`）を main にマージすると、定期自動更新（`docs/20260923_0000_市議会データの定期自動更新.md`）が `tagawa:build-csv` で CSV を作り直し、本文が変わった会期（r8-6-teirei）を本番DBへ差分投入して再検証する。生成物の CSV はこの変更には含めず、自動更新のコミットに任せる。

図の描画はデプロイ後に効くため、本番DBへの投入はデプロイ完了後に行う（先に入れるとコードブロックのまま表示される）。翌朝 06:00 JST を待たずに反映するときは、デプロイ完了後に `gh workflow run council_auto_update.yml --ref main` で起動する。手で入れる場合は次のとおり。

```bash
pnpm --filter @mirai-gikai/seed tagawa:build-csv
npx dotenv-cli -e <本番env> -- node scripts/upsert-sessions.mjs r8-6-teirei
curl -X POST https://tagawa-gikai.jp/api/revalidate -H "Authorization: Bearer <REVALIDATE_SECRET>" -H "Content-Type: application/json" -d '{"tags":["bills"]}'
```

## 今後

- 他の予算議案（当初予算・決算）にも `budget-chart` を書けば同じ図が出る。解説を書くときに、議案説明資料の総括表から総額と主な内訳を写す
- 用語集は `glossary.ts` に足すだけで本文の印と一覧の両方に効く。説明は「制度がどう動くか」を淡々と書き、評価を含めない
