# トップページの並び替え（市長が代わってからの動きを先に）

## 背景

令和8年7月13日に市長が代わり、9月定例会（9月7日〜10月8日）が新市長のもとで初めての定例会になった。サイトを見に来る人の関心は「市長が代わってから何が動いたか」にあるのに、トップページは次の状態だった。

- ヒーローの下が「本日は閉会中」で、新市長の動きは1行のバナーだけ
- タグ別セクションの順が 決算 → 意見書 → 条例 → 予算 → 決議。運営が決めた順（条例 → 予算 → 意見書 → 決算 → 決議）ではなく、異議なく可決された意見書のセクションが自動で上に上がっていた
- 決算の枠は前市長の時期の不認定（令和6年度・令和5年度）が先で、10月8日に議決された令和7年度の決算は3番目。予算の枠には当初予算が出ていなかった

## 並びの決め方

「いま関心が高いか（市長が代わってからの動きか）」と「解説の中身が厚いか」の2つで決めた。

### ページの構成（コード）

| 順 | ブロック | 変えたこと |
| --- | --- | --- |
| 1 | ヒーロー | 変更なし |
| 2 | 市長が代わってからの動き | 1行のバナーを、最新3件の見出し（日付つき）を並べるブロックにした。全体が `/mayor` の「就任後にしたこと」へのリンク |
| 3 | 本日は閉会中／会期中 | 閉会中は「直近の議会」（終わったばかりの会期）を示し、その会期のまとめ・一般質問・会議の記録へのリンクを出す |
| 4 | 注目の議案 | 並びは本番の設定（下記） |
| 5 | タグ別セクション | 並びは本番の設定（下記） |
| 6 | 過去の議会アーカイブ、みらい議会とは | 変更なし |

2 と 3 は「いま関心が高い順」に入れ替わる。**閉会中は市長の動きが先、会期中は開かれている議会が先**（`web/src/app/(main)/page.tsx`）。

### タグ別セクションの自動昇格の条件（コード）

「直近90日以内に話題の議案が出たタグを上に上げる」しくみは、興味度スコアが50を超えるかで判定していた。ところが、解説に定型で入る「反対討論」「議会での主な論点」の加点と新しさの加点だけで55点になり、異議なく可決された議案でも条件を満たしてしまう。そこで判定を **否決・不認定・継続審議など異例の議決が直近90日以内にあったか** に改めた（`isHotTopicBill`）。運営が決めた順を覆すのは、議決そのものが異例だったときだけになる。

注目の議案に入れた議案はタグ枠に出ないので、この判定には数えない。

### 注目の議案・タグの順・タグ枠の固定（本番の設定）

admin の「トップページ編集」と同じ列を `scripts/set-homepage-curation.mjs` で入れ替えた（2026-10-13）。選んだのはすべて市長が代わってから（令和8年8月臨時会・9月定例会）の議案で、予算の枠だけ、いま執行されている令和8年度の当初予算を入れている。

- **注目の議案**（新しい順）: 令和7年度一般会計決算（10月8日、不認定）→ 令和8年度一般会計補正予算（9月29日、図つきで解説がいちばん厚い）→ 政治倫理条例検討特別委員会の設置（9月7日、10月も審議が続いている）
- **タグの順**: 予算 → 決算 → 条例 → 決議 → 意見書。市のお金の使い方（予算・決算）、ルール（条例）、議会としての意思表示（決議・意見書。国や県に向けたものが多い）の順
- **タグ枠の固定**
  - 予算: 追加の補正予算（熊本地震の災害復旧）／令和8年度一般会計予算／平成筑豊鉄道を支える基金の特別会計の補正
  - 決算: 病院事業会計／平成筑豊鉄道を支える基金の特別会計／国民健康保険特別会計
  - 条例: 市長の給料の減額に関する条例の改正（市長交代に伴う）／白鳥工業団地の地区計画／投票立会人などの報酬
  - 決議: 福岡県政に対する信頼回復を求める決議／調査特別委員会の委員の定数2件
  - 意見書: 非核三原則の堅持／地方財政の充実・強化／民生委員・児童委員の担い手確保

副市長の選任（8月10日、無記名投票で賛成13・反対4）は関心の高い議案だが、要約に調査特別委員会に関する反対討論の理由が入るため、注目の議案には入れていない（編集方針「特定の人を疑わせる見せ方は避ける」に照らした判断。入れる場合は admin の「トップページ編集」で追加できる）。

## 次に見直すとき

- 固定した議案は次の会期が始まっても自動では入れ替わらない。12月定例会の議案が出そろったら、admin の「トップページ編集」か `scripts/set-homepage-curation.mjs` で入れ替える
- 変更前の設定の控えと今回の定義は、リポジトリの外の `committee-work/homepage-curation/` に置いている
- トップの「市長が代わってからの動き」は `MAYOR_ACTIONS`（`web/src/features/mayor/shared/data/mayor-profile.ts`）の新しい3件。委員会記録を取り込んで追記すれば自動で入れ替わる
