# 市議会データの定期自動更新

## 目的

公式サイト・公式YouTubeに新しい市議会の内容が出たら、人が気づいて手で取り込むのを待たずにサイトへ反映する。人にしかできないこと（解説文の執筆、中継動画の要約）は GitHub Issue にまとめて残す。

## 仕組み

GitHub Actions の `.github/workflows/council_auto_update.yml` が **毎日 06:00 JST** に動く（`workflow_dispatch` で手動起動もできる）。1回の実行で次を順に行う。

| 手順 | コマンド | 結果 |
| --- | --- | --- |
| 議案と議決結果 | `tagawa:scrape` → `tagawa:scrape-explanation-materials` → `tagawa:build-csv` | `packages/seed/tagawa/data/sessions.json`、`packages/seed/csv/data/*.csv` |
| 請願・陳情 | `tagawa:scrape-petitions` | `web/src/features/petitions/shared/data/petitions-data.ts` |
| 一般質問の録画 | `tagawa:update-question-videos` | `packages/seed/tagawa/data/question-videos.json` |
| 一般質問の通告 | `tagawa:scrape-questions` | `web/src/features/general-questions/shared/data/general-questions-data.ts` |
| 委員会記録に無い動画 | `tagawa:find-unrecorded-videos` | レポート用（本番DBの `committee_meetings` と照合） |
| 変更の検出 | `tagawa:detect-changes` | `report.md` / `commit-subject.txt` / `outputs.env` |

変更があれば `pnpm lint` / `pnpm typecheck` / seed と web のテストを通してから **main に直接コミット**し、`deploy.yml` と `integration_test.yml`（visual-smoke を含む）を `workflow_dispatch` で起動したうえで、変わった会期だけ `scripts/upsert-sessions.mjs` で本番DBへ差分投入 → `/api/revalidate` で再検証する。GITHUB_TOKEN による push は push トリガーの CI を起こさないため、この順序にしている。Code Check は起動しない（起動すると `workflow_run` 経由でデプロイが二重に走る。同じ検証はジョブ内で済ませている）。

「変わった会期」には、会期データ（sessions.json / ongoing-sessions.json）が変わった会期のほか、**解説文（`bill-descriptions*.ts`）の変更が CSV の本文に現れた会期**も含む。解説を書いて main にマージすれば、翌朝の自動更新で本番DBに入る（手で `upsert-sessions.mjs` を叩いてもよい）。

本番DBへの投入に失敗した日は、コミットとデプロイは済んだ状態でジョブが赤になり、ジョブのサマリーに手当てのコマンドが出る。

### 自動で決まること

- 閉会後に「提出議案と議決結果」ページが公開されると、`tagawa:scrape` がその会期を取り込み、`data/ongoing-sessions.json`（会期中の会期を手で置くファイル）から同じ会期を自動で外す（`pruneOngoingSessions`）
- 公式の一覧ページから外れた古い会期は前回の出力を引き継ぐ（`carryOverMissingSessions`）。議案説明資料のページが取得できない会期は前回のリンクを残す
- 新しい議案は公式ページの事実（件名・提出者・議決結果）だけで公開される。解説文は人が書く（下記）
- 一般質問の録画は日付と議員名で自動的に結び付く。新年度のチャンネルは `packages/seed/tagawa/data/question-video-channels.json` に追加する

### 人の作業が残るもの（Issue）

`needs_follow_up` のときだけ、ラベル `council-update` の Issue を1つ作って本文を最新のレポートに置き換える（データが変わった日はコメントで知らせる）。作業が無くなった日に自動で閉じる（ジョブが途中で失敗した日は閉じず、本文の先頭に失敗した旨を添える）。

- **解説文がまだ無い議案**: `packages/seed/tagawa/bill-descriptions*.ts` に書いて main にマージする。翌朝の自動更新で本番DBに入る（急ぐなら `tagawa:build-csv` → `scripts/upsert-sessions.mjs <slug>` → `/api/revalidate`）
- **公式ページから無くなった議案／解説文が外れた議案**: 件名や番号の表記が変わったときに起きる。本番DBの古い行は自動では消えないので確認する
- **委員会記録にまだ無い中継動画**: 直近90日の動画だけを個別に載せ、それより前の動画は畳んで件数と一覧を載せる（古い動画の山だけでは Issue を開いたままにしない）。手順は `docs/20260912_1500_最新会期の取り込み_8月臨時会と9月定例会.md`（字幕 → 要約 → `scripts/import-committee-meetings.mjs`）。自動字幕が無い動画は音声認識（faster-whisper、`committee-work/yt2026c/stt.py`。1時間の音声に30〜60分）で文字起こしして取り込める。発言が無いなど取り込めない動画は `packages/seed/tagawa/data/unrecorded-video-exceptions.json` に理由付きで置くと検出から外れる
- **警告**: yt-dlp が動画一覧を取れなかった、公式サイトから会期が消えた、ongoing-sessions.json のキーが公式ページの会期と食い違った、など

## Secrets

リポジトリの Secrets に `SUPABASE_URL`、`SUPABASE_SECRET_KEY`（本番の service_role JWT。新形式の sb_secret_ は使えない）、`REVALIDATE_SECRET` を登録済み（2026-09-23）。無い環境（fork など）ではDB投入と再検証を飛ばし、コミットとデプロイ起動だけを行う（未収録動画の検出もできないため、その旨の警告が Issue に載る）。

## 手元で同じことを確かめる

```bash
OUT=/tmp/council-update
pnpm --filter @mirai-gikai/seed tagawa:scrape
pnpm --filter @mirai-gikai/seed tagawa:scrape-explanation-materials
pnpm --filter @mirai-gikai/seed tagawa:build-csv
pnpm --filter @mirai-gikai/seed tagawa:scrape-petitions
YT_DLP=<yt-dlpのパス> pnpm --filter @mirai-gikai/seed tagawa:update-question-videos -- --out $OUT
pnpm --filter @mirai-gikai/seed tagawa:scrape-questions
npx dotenv-cli -e <本番env> -- pnpm --filter @mirai-gikai/seed tagawa:find-unrecorded-videos -- --out $OUT
pnpm --filter @mirai-gikai/seed tagawa:detect-changes -- --out $OUT
```

`tagawa:scrape` 系は `packages/seed/tagawa/.cache` に取得結果をキャッシュする。公式ページの更新を取り込み直すときは該当ページのキャッシュを消す（Actions は毎回まっさらなので気にしなくてよい）。

## 失敗したとき

- ワークフローが赤になると GitHub から通知が来る。多いのは公式サイトの一時的な不調（再実行で直る）と、ページ構造の変更（パーサーの修正が必要。`packages/seed/tagawa/*.test.ts` に実物の断片を足して直す）
- YouTube が Actions からの一覧取得を拒む日は、録画リンクの更新と未収録動画の検出だけを飛ばして続行する（警告が Issue に載る）
- `main` へのコミットが他の変更と競合したら rebase を試み、だめなら失敗させる（手で取り込む）
