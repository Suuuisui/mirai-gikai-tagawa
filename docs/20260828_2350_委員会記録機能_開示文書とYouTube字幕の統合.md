# 委員会記録機能: 情報開示請求文書とYouTube字幕の統合

## 背景

田川市議会の委員会（常任委員会・特別委員会）の議事録は公式には公開されていない。
運営者が情報開示請求を行い一部の議事録を入手したが、開示されたのは以下のみ:

- 総務文教委員会: 令和3年1月〜令和4年3月の12回分
- 指名競争入札による建設工事発注に関する調査特別委員会（百条委員会）: 令和7年9月〜令和8年2月の4回分

開示されなかった期間・委員会は、公式YouTubeチャンネル（田川市議会中継）の
中継動画の自動字幕をテキスト化して補完する。

## データソース

| 出典 | source_type | 範囲 |
| --- | --- | --- |
| 情報開示請求で入手したPDF（議事録・概要・記録・議題） | `disclosure` | 総務文教12回 + 入札百条委4回 |
| 公式YouTube中継の自動字幕（ja-orig） | `youtube` | 委員会系動画 130回分（議会運営・総務文教・厚生・建設経済・一般廃棄物特別委・公選法検証特別委・個人情報漏えい調査特別委・全員協議会等）。2チャンネルにまたがる（後述） |

- 同一会議が両方に存在する場合は開示文書（disclosure）を正とし、YouTube版は
  投入せず開示レコードの `youtube_url` に中継URLを紐づける。
- 一般質問・本会議の動画は、本会議録が公式の会議録検索システムで公開されている
  ためスコープ外。

## スキーマ

`committee_meetings`（マイグレーション: `20260828120000_add_committee_meetings_table.sql`）

- 会議1回 = 1行。`(committee_name, meeting_date, source_type)` で一意（upsert可能）
- `summary` / `key_points` / `agenda_items` / `attendees` はAIによる整理結果
- `minutes_text` に原文テキスト（PDF抽出 or 字幕起こし）を全文保持

## パイプライン

1. **開示PDF**: Google Drive（開示結果フォルダ）から Drive API でテキスト抽出 →
   会議単位のJSONに構造化（要点・要約はAIが議事録全文から生成）
2. **YouTube**: `yt-dlp --flat-playlist` でチャンネル全動画を列挙 → タイトルから
   開催日・委員会名をパース → `--write-auto-subs --sub-langs ja-orig` で字幕取得 →
   VTTをテキスト化（ロールアップ重複除去）
3. **AI整理**: summary / key_points / agenda_items / attendees を生成する。
   `web/scripts/summarize-committee-meetings.mjs`（AI Gateway 経由）を用意して
   いるが、Vercel AI Gateway の Free tier ではレート制限で一括処理が通らない
   （gpt-4o-mini / gemini-3-flash とも 429）。初回の97会議は Claude のサブ
   エージェント（1体あたり3〜5会議、1件ごとにファイル書き出し）で生成した。
   Fable 5 がセッション制限に達した場合は `model: "opus"` を指定して継続する。
4. **投入**: `scripts/import-committee-meetings.mjs` が中間JSONを
   `committee_meetings` へ upsert

### 字幕の誤変換補正

YouTube自動字幕は人名・固有名詞の誤変換が多いため、AI整理のプロンプトに
`web/src/features/members/shared/data/member-profiles.ts` の議員名簿（25名）と
地名・団体名のリストを渡し、文脈から正しい表記へ補正させている。
実例: 「長松」→永松広宣、「坂木原」→榊原大祐、「克木竜一」→香月隆一、
「小崎」→尾﨑行人、「音楽川河川事務所」→遠賀川河川事務所、「湯丸駅」→油須原駅、
「最上組合」→田川地区斎場組合、「星井」→糒、「慎重者整備事業費」→新庁舎整備事業費。
名簿で確定できない人物は氏名を推測せず役職名で表現する方針とした。

**市長の交代に注意**: 村上卓哉市長は令和8年5月31日に退職し、令和8年7月12日の
市長選で浦野仁（うらの じん）氏が初当選、7月13日に就任した。字幕では新市長名が
前市長名に誤変換されやすいため、2026年の記録を扱う際は日付で判別すること。

## 表示

- `/committees` 委員会別グループの一覧（出典バッジ付き）
- `/committees/[id]` 概要・要点・議題・出席委員・中継リンク・記録全文（折りたたみ）
  - 出典と「AIによる整理であり原本を確認すべき」旨の注意書きを必ず表示する

### YouTubeチャンネルが年度ごとに分かれている点に注意

田川市議会の中継は年度単位で別チャンネルに分かれている。現時点で取り込み済みなのは:

- `UCiOB5teYzRNX5N8-VkDNbfg`（〜令和7年）— 委員会系83会議
- `@2026年令和8年田川市議`（令和8年）— 委員会系47会議

新年度になったら新しいチャンネルが立つ可能性があるため、取り込み前にチャンネルの
有無を確認すること。

## 運用メモ

- 新しい中継動画が公開されたら手順2〜4を再実行すれば追記される（upsertのため冪等）
- 追加の開示文書を受領したら手順1のJSONを作り直して再投入する
- 本番投入は本番Supabaseの `SUPABASE_URL` / `SUPABASE_SECRET_KEY` を環境変数に
  与えて手順4を実行する（`vercel env pull` で取得できる）
- 本番へのマイグレーション適用は Supabase ダッシュボードの SQL Editor から行う
  （CLIは別アカウントにログインしており田川プロジェクトを操作できない）
- 中間データはリポジトリ外の `committee-work/` に保管する
  （`yt-split/` が字幕の生データ、`yt-out/` が要約済み、`import-ready.json` が投入用）
- 新しい施設名・団体名が出てきたら、AI整理時の固有名詞リストに追加すること
