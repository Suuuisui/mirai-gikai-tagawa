# 選挙の投票率ページ（/elections）

## 目的

市選挙管理委員会への情報開示請求（令和8年9月24日付、田情第35号）で交付を受けた
投票結果の集計資料を使い、投票への参加を考える材料を市民に見せる。
編集方針（猜疑心を持たせない・事実を淡々と・参加を促すデータを優先）に沿い、
特定の地域や世代を評価・順位づけする見せ方はしない。

## データ源

| 内容 | 出典 | 置き場所 |
| --- | --- | --- |
| 令和8年7月12日 市長選挙・市議補選、令和5年4月23日 市議一般選挙の投票区別（当日有権者・当日／期日前／不在者投票者数）と1歳刻みの年代別投票者数 | 選管「投票結果速報集計用紙（結了報告）」「年代別 投票者数・投票率」（開示文書、12ページ） | `web/src/features/elections/shared/data/turnout-data.ts` |
| 平成23年〜令和5年の市議選の投票率・期日前／不在者投票者数 | 同じ集計用紙の欄外 | 同上 `COUNCIL_ELECTION_HISTORY` |
| 7月12日当日の時刻ごとの投票者数 | 市「投・開票速報」PDF（公開） | 同上 `MAYOR_ELECTION_2026_DAY_PROGRESS` |
| 投票区ごとの投票所 | 選管「選挙人名簿登録者数（令和8年9月1日現在）」 | 同上 `POLLING_PLACES_2026` |
| 当日投票所を7〜18時に短縮する方針 | 選管の方針（令和8年8月） | 同上 `POLLING_HOURS_POLICY` |

- 人数は男女別の値だけを転記し、計・投票率は `shared/utils/turnout.ts` で計算する。
  `turnout-data.test.ts` が資料に印刷された小計・合計・投票率・5歳刻みの小計と照合する
  （転記時に726個の投票率すべてが資料の値と一致することを確認済み）。
- 資料の「19未満」は18歳、「80以上」は80歳以上として持つ。
- 資料にある担当職員の氏名は転記しない。

## ページ構成

1. 冒頭: 市長選の投票率（58.08%）、投票した人・しなかった人・期日前投票の人数
2. あなたと同じ年齢の人は（年齢・性別を選ぶ Client Component。令和5年の同じ年齢と比較）
3. 年代別の投票率（5歳刻み、令和8年＝キーカラー、令和5年＝灰色。表で見る付き）
4. 年代別の票の数（5歳刻みの積み上げ棒。令和8年10月2日に追加、`docs/20261002_2230_選挙ページに年代別の票の数を追加.md`）
5. 投票した人の年代（有権者に占める割合と投票した人に占める割合）
6. 期日前投票と当日（期日前の割合、当日の時刻ごとの累計、18時以降の人数、投票時間短縮の方針）
7. 投票区別（番号順。順位づけしない。令和5年とは区域が違うので比較しない）
8. 市議選の投票率の推移（補欠選挙は単純比較できない旨を明記）

グラフは BudgetChart と同じく div の棒＋文字の値で組み、棒は aria-hidden。
色は注目＝`bg-primary`、比較＝`bg-mirai-text-placeholder`（#949494）の2色だけ（積み上げ棒の残りだけ、キーカラーの明るい段 `bg-mirai-chart-remainder` を使う）。
dataviz の検証スクリプトで、色覚の違いでの差（ΔE 30.1）と白地へのコントラスト（3:1以上）を確認した。
差（ポイント）は表示に使う丸めた値どうしで計算する（`pointDiff`）。
棒の長さは議案の予算グラフと同じ `barWidthPercent`（bills/shared/utils/budget-chart.ts）を使う。
年齢を選ぶ部品には転記した行（`AgeRow`）だけを渡し、集計は部品の中で行う（RSC の転送量を抑えるため）。
