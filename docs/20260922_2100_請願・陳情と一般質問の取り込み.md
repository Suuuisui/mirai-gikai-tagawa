# 請願・陳情と一般質問（通告）の取り込み

## 背景

公式サイトには「請願・陳情の審査状況と審査結果」と、定例会ごとの「一般質問一覧」が公開されているが、どちらもみらい議会＠田川市では扱っていなかった。市民からの要望がどう扱われたか、議員が何を市に問うたかは、議案と並んで議会の働きを知る手がかりになるため、サイトで拾えるようにする。

## データの持ち方

DBは使わず、公式ページをスクレイパーで読み取って **web 側の静的データ（TypeScript）** として書き出す。件数が小さく（請願・陳情44件、一般質問353件）、運営者が編集する必要も無いため、マイグレーションや本番投入の手順を増やさない。

- 型: `packages/shared/src/council/types.ts`（seed と web の両方から参照）
- 生成物:
  - `web/src/features/petitions/shared/data/petitions-data.ts`
  - `web/src/features/general-questions/shared/data/general-questions-data.ts`
- 生成コマンド（`packages/seed`）:
  - `pnpm --filter @mirai-gikai/seed tagawa:scrape-petitions`
  - `pnpm --filter @mirai-gikai/seed tagawa:scrape-questions`
- 取得したHTML・PDFは `packages/seed/tagawa/.cache` にキャッシュされる。公式ページが更新されたときは該当ページのキャッシュ（`petitions-kiji….html` / `questions-kiji….html`）を消して再実行する

### 請願・陳情（`petition-parser.ts`）

- 対象ページ: 「請願・陳情」一覧（list00713）にある「審査状況と審査結果」4ページ（平成23年5月〜）
- 表の列（番号 / 件名＋PDF / 紹介議員 / 上程 / 付託委員会 / 審査状況・結果【措置】）を読み取り、日付の書式（令和5年6月19日・H27.9.4）、字間の空白（採　択）、項目ごとの結果（（1）採択 （2）不採択）を吸収する
- `status` は 採択 / 不採択 / 一部採択 / 取り下げ / 審議未了 / 継続審査 / 審査中 に分類する
- 紹介議員は `council-names.ts` で「姓 名」に正規化し、異体字（榊󠄀原→榊原、村𠮷→村吉、辻󠄀→辻）を議員ページのキーに揃える

### 一般質問（`question-parser.ts` / `question-outline-parser.ts` / `question-video-matcher.ts`）

- 対象ページ: 「一般質問一覧」（list00706）の定例会ごとのページ36枚（平成29年〜）。「（延期分）」ページは同じ会期に統合する（同じ順番は延期分を優先）
- 表（順番 / 質問者（会派） / 質問事項）と、表の手前の「1日目：9月9日（水曜日）」から質問日を決める。古いページでは日付行が表の中にあるため、表の行も見る
- 通告書PDFがある会期（令和5年6月〜）は `pdftotext -layout`（poppler）で本文を取り出し、議員ごとの要旨（⑴⑵…とア・イ…）を読み取る。項目数が公式ページと一致すれば公式ページの表記を項目名に使う
- 公式YouTubeチャンネルの録画は `data/question-videos.json`（動画ID・タイトル）から、日付と議員名で結び付ける。チャンネルは年度ごとに分かれる（`UCiOB5teYzRNX5N8-VkDNbfg`＝〜令和7年、`@2026年令和8年田川市議`＝令和8年）ので、新年度は新チャンネルも確認する
  ```bash
  yt-dlp --flat-playlist --extractor-args "youtube:lang=ja" --print "%(id)s\t%(title)s" <チャンネルURL>
  ```

### 議員名の扱い

- 姓のリスト（`packages/shared/src/council/family-names.ts`）を seed と web で共有し、web のテストで議員プロフィールのキーがすべて載っていることを確認する
- 同じ姓の別人（髙瀬冨士夫と髙瀬春美）を混同しないよう、議員ページへのリンクと議員ページの「一般質問で取り上げたこと」は、公式名簿のフルネームと一致する記録だけに絞る（`question-links.ts` / `selectQuestionsByMember`）

## 画面

- `/questions`: 最新の定例会の一般質問を全文（質問事項・要旨・録画・その日の本会議の記録・通告書PDF）で載せ、それ以前の定例会は一覧から `/questions/[sessionKey]` へ
- `/questions/[sessionKey]`: 定例会1回分。前後の定例会へのナビと、会期まとめページへの導線
- `/petitions`: 審査中のものを先頭に、これまでの結果を上程日の新しい順に。付託先は委員会の記録がある委員会だけリンク、紹介議員は議員ページがある議員だけリンク
- 会期まとめページに「この会期の一般質問」「この会期の請願・陳情」、議員ページに「一般質問で取り上げたこと」、トップの会期バナーに「この会期の一般質問（N人）を見る」を追加
- ヘッダー（PC・スマホ）、ハンバーガーメニュー、フッター、サイトマップに導線を追加。PCナビは7項目になったので、1024px幅ではアイコンを省いて収める

## 確認したこと

- `pnpm lint` / `pnpm typecheck` / `pnpm test`（seed のパーサー・web の純粋関数にテスト）
- ローカル Supabase で web を起動し、375px と 1280px（ヘッダーは 1024px も）で Playwright 撮影して目視確認。横はみ出し・コンソールエラーなし。`pnpm smoke:visual` 通過

## 運用メモ

- 定例会ごとに公式サイトが更新されたら、`tagawa:scrape-questions` を再実行してコミットするだけで反映される（会期のキャッシュを消すこと）。請願・陳情も同様
- 要旨を読み取れない議員（見出しの書式が違う等）は `outline: null` になり、画面では質問事項だけを出す。件数のずれは `scrape-questions` の出力（要旨 N）で分かる
- 要旨の区切りが公式ページの項目数と合わない議員（令和5年の4人）は、項目に紐付けず「通告書に書かれた要旨」として畳んだ別枠で出す
- 一般質問の答弁の要約は委員会記録の「本会議（一般質問）」（日ごと1件）に依存する。新しい定例会の録画を取り込んだら、その日付の記録があれば自動でリンクされる
