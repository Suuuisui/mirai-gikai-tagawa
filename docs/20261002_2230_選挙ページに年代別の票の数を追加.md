# 選挙ページに「年代別の票の数」を追加

## きっかけ

運営者（田川市政ラボ）から「投票率だけでなく、投票数の方が年齢ごとの意見の強さを表せそう」という提案（2026-10-02）。
投票率はその年代の中での割合で、選挙の結果を左右するのは票の数（＝投票した人の数。1人1票）。
両者は「票の数 ＝ 有権者の数 × 投票率」の関係にあり、投票率のグラフだけでは年代ごとの票の重みは見えない。

## 見せ方

- 場所: 「年代別の投票率」の直後、「投票した人の年代」（3区分の割合）の前。ジャンプナビは「年代別の投票率」「年代別の票の数」と対にした
- グラフ: 5歳刻みの積み上げ棒。棒全体＝有権者の数、濃い青＝投票した人（票の数）、明るい青＝投票しなかった人。
  1本の棒で「人数（有権者）」と「票の数」と「割合（投票率）」が同時に読める。棒の右には票の数、ラベルの下に有権者の数
- 目盛り: 有権者の最大（80歳以上 5,121人）を千人単位で切り上げた 0〜6,000人
- 要点の文:
  1. 票の数は「有権者の数 × 投票率」で決まること（投票する人が増えればその年代の票も増える）
  2. 1歳ごとの票の最少（24歳 97票）と最多（77歳 603票）、約6.2倍の開きを、有権者の数（約2.6倍）と投票率（約2.4倍）の違いに分けて説明
- 表で見る: 票の数・投票した人全体に占める割合・投票しなかった人・有権者（計の行付き）

## 編集方針との関係

- 年代を評価・順位づけする言い回し（「〜が強すぎる」「シルバー民主主義」など）は使わない。年代は若い順に並べ、票の数で並べ替えない
- 「若い世代が投票しないから」とだけ読めないよう、有権者の数の違い（人口の大きさ）と投票率の違いの両方を示す
- 「80歳以上」は資料で80歳から上が1行にまとまっているため、1歳ごとの比較（最少・最多）から外す（`singleYearAges`）。
  5歳刻みのグラフでは、18・19歳が2歳分、80歳以上が80歳から上をまとめた人数であることを注記する

## 色

積み上げ棒の「投票しなかった人」は、キーカラー（DADS blue-900 `#0017c1`）の明るい段 DADS blue-400 `#7096f8` を
トークン `--color-mirai-chart-remainder` として追加した。dataviz の検証スクリプト（ordinal、白地）で
明るい側が 2.84:1（下限 2:1）、明度が単調、色相のずれ 2° を確認。blue-300（`#9db7f9`）は 1.99:1 で下限に届かなかった。
既存の灰色（比較の系列）を使うと「令和5年」と同じ意味に見え、面積も重くなるため使わない。
値は棒の右・読み上げ用の文・表に必ず文字で出すので、色だけに頼らない。

## 実装

- 集計: `votesByAgeBand`（5歳ごとの票の数・投票しなかった人・全体に占める割合）、`singleYearAges`、`timesOf` / `formatTimes`（倍率）、`formatVotes`（`shared/utils/turnout.ts`）
- 部品: `StackedBarRow`（`server/components/turnout-bars.tsx`。区分の間は2pxのすき間、右端だけ丸める）。`BarGroupRow` と行の枠（`ChartRow`）を共有
- セクション: `server/components/age-votes-section.tsx`（実データで文言・合計を確かめるテスト付き）
- 倍率のうち投票率どうしの比は、画面に出す丸めた値（29.5% と 70.5%）で計算して表示と食い違わないようにした
