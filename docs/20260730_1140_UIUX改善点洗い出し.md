# UI/UX改善点の洗い出し（2026-07-30）

本番サイト（https://tagawa-gikai.jp）を agent-browser でスマホ幅（375px）・PC幅（1280px）の両方で実際にスクロールしながら確認した結果。運用手順は[運用保守ガイド](./20260716_1100_運用保守ガイド.md)、直近の課題は[課題とロードマップ](./20260722_2030_課題とロードマップ.md)を参照。

対象ページ: トップ、議案詳細、議員一覧、議員個人、検索、会期一覧（Archive）、会期別議案一覧。AIチャットは実際に質問して応答を確認済み。

## 良い点

- 議案がカテゴリ別（注目・条例・予算・意見書・決算・決議）にセクション分けされ、ステータス・賛否・要約がカード一目で分かる
- AIチャットの導線設計: 質問例ピルで最初のハードルを下げ、回答は簡潔＋議案への内部リンク付き＋「AIの回答は間違えることがあります」という免責表示も適切な位置にある
- 議案詳細のナビゲーション: パンくず・目次・「審議のステータス」のビジュアルなステップ表示など、長い文章に迷わない工夫がある
- 「賛成・反対の数は議員の評価を示すものではありません」という注記が各所にあり、恣意的な印象操作を避ける配慮が徹底している

## 改善点（優先度順）

### 1. PC版のレイアウトがスマホ版の引き伸ばしになっている（最大の課題）

検索ページ・会期一覧ページ・議案詳細ページなど、1280px幅の画面でもコンテンツ列が375〜620px程度しかなく、左右が広大な余白のまま。

- `/search`: 検索前の状態がほぼ空白（検索窓＋タグのみ）で間延びして見える
- `/archive`: 令和元年〜令和8年の全会期が単一列の縦並び。PCなら2〜3列グリッドにできるはずで、ページが不必要に長い（4387px）
- `/bills/[id]`: 本文カラム幅がモバイルとほぼ同じ幅感（375px程度）

### 2. AIチャットパネル（PC版）が画面上部にしか表示されない

トップページも議案詳細ページも、右カラムのAIチャットは最初のビューポート内だけに表示され、下にスクロールすると右側は空白カラムになる（`top-pc-01`〜`06`, `bill-pc-full` で確認）。`position: sticky` にすれば、長い議案本文を読みながら常時アクセスできる。

### 3. 検索ページの初期状態に何も出ない

「全611件の議案からキーワードで検索できます」という情報量なのに、検索前は検索窓とタグのみ。人気キーワードや最近の議案のプレビューがあると、検索へのきっかけになる。

### 4. 議案詳細の「具体的な内容」が長大な箇条書き

16項目以上が縦一列に並び、スキャンしづらい（例: 議案第7号 令和8年度当初予算）。カテゴリ別グルーピングや折りたたみ表示が有効そう。

### 5. スマホのAIチャットモーダルの閉じるボタンがやや小さい

質問ピルタップ後に開くモーダルの右上「✕」がタップターゲットとして少し心もとない大きさ。

## 対応方針

デザイン判断（PC版でどこまでコンテンツ幅を広げるか、AIパネルのsticky化の挙動）を伴うため、着手前にユーザーへ優先順位を確認する。
