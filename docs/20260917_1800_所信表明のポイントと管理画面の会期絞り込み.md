# 所信表明のポイント表示と、管理画面の会期絞り込み

## 背景

- 9月7日の本会議で浦野市長が行った所信表明は、`/mayor` の「就任後にしたこと」の
  1項目（1段落の説明）にしか載っておらず、4つの改革の中身が読み取りにくかった
- 管理画面（admin）の議案一覧は全会期の議案（628件）が1つの表に並び、会期での
  絞り込みが無いため、最新の会期（令和8年第6回9月定例会）の議案を探して編集するのが
  手間だった

## 変更

### /mayor に「所信表明で何をすると言ったか」を追加

- データは `web/src/features/mayor/shared/data/mayor-profile.ts` の `MAYOR_POLICY_SPEECH`
  （基本姿勢3点・最優先分野・4つの改革〔目指す姿＋具体策〕・そのほかの取り組み・
  本会議での訂正・出典）。言い回しは本人の言葉の範囲に留め、政策の中身を推測で補わない。
  出典は公式YouTubeの本会議中継（自動字幕）。会議録が公開されたら照合する。
  9月7日の本会議を指す出典は `SEPTEMBER_SESSION_OPENING` に1つだけ書き、
  就任後の出来事・所信表明・会期の案内の3か所から参照する（日付もそこから取る）
- 表示は `policy-speech-section.tsx`。ヒーロー直下（「就任後にしたこと」の前）に置き、
  ジャンプナビに「所信表明のポイント」を追加。4つの改革は番号付きカード（PC幅で2列）
- 出典リンクは本会議の記録（ローダーで解決）と中継映像
- `mayor-profile.test.ts` で「改革が4つ・各改革に具体策がある・就任後の出来事として
  `MAYOR_ACTIONS` に同じ日付がある」ことを機械的に守る

### admin の議案一覧に会期の絞り込み

- `?dietSession=<diet_session_id>` で会期を絞り込む（`parseBillListFilter` がUUID以外を捨てる。
  admin では「session」がインタビューセッションも指すので `dietSession` にした）。
  セレクトの候補は `loadDietSessions()`（開会日の新しい順）なので最新の会期がすぐ選べ、
  アクティブな会期には「（アクティブ）」を添える
- セレクトは interview-reports にあった `FilterSelect` を `components/ui` に昇格させて共用。
  絞り込みはソート（`?sort=` / `?order=`）を保ったまま `router.replace` でURLに写す
  （`BillSessionFilter`）。議案と会期の取得は `BillList` 内で並列に行う
- 既定の並び（`created_at` の新しい順）はそのまま。取り込んだ議案の `created_at` は
  議決日・提出日なので、絞り込まなくても最新の会期の議案が上に来る
- 会期管理ページの一覧はもともと開会日の新しい順（変更なし）
