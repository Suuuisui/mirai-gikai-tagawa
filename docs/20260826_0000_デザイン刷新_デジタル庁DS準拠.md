# デザイン刷新: デジタル庁デザインシステム準拠トーンへの変更

## 背景・目的

従来のデザインはテラコッタ基調＋ピンク系グラデーション＋大きな角丸（ピル形状）＋英字飾りタイポの組み合わせで、いわゆる「AIスタートアップ風」の印象が強かった。市議会の議案情報を扱う公共性の高いサービスとして、行政サイトらしい信頼感のある見た目に刷新する。

参考: [デジタル庁デザインシステム（DADS）](https://design.digital.go.jp/) および `@digital-go-jp/design-tokens` v2.0.1 のプリミティブカラー。

## デザイン方針

| 項目 | 旧 | 新 |
| --- | --- | --- |
| キーカラー | テラコッタ `#b5432a` / `#8f2f1c` | DADS blue-900 `#0017c1` / blue-1000 `#00118f` |
| 背景 | ベージュ `#f7f4ee` | 白 `#ffffff` |
| 本文テキスト | `#1f2937` | DADS solid-gray-900 `#1a1a1a` |
| 面・罫線 | 暖色系グレー各種 | DADS solid-gray 50-300（`#f2f2f2` / `#e6e6e6` / `#cccccc` / `#b3b3b3`） |
| グラデーション | ピンク系 `bg-mirai-gradient` ほか | 全廃。薄青のフラット面 `bg-mirai-surface-key`（blue-50 `#e8f1fe`）に置換 |
| 角丸 | `--radius: 10px`・ピル形状多用 | `--radius: 8px`・`rounded-lg` / `rounded-md` 基調 |
| ボタン | 黒枠＋グラデ＋rounded-full | 青ベタ白字（default）/ 青枠白地（outline）＋rounded-lg |
| 影 | カラム全体に `shadow-lg` 等 | 罫線区切り中心。影は原則廃止 |
| 見出し | 英字飾りSVG（About / Archive） | 日本語見出し＋左に `border-l-4 border-primary` の縦線 |

## 主な変更点

### デザイントークン（`web/src/app/globals.css`）

- `--color-mirai-*` の全トークンを DADS プリミティブ値へスナップ。
- 新トークン `--color-mirai-surface-key`（blue-50）/ `--color-mirai-surface-key-subtle`（light-blue-50）を追加し、旧 `bg-mirai-gradient` / `bg-mirai-light-gradient` の使用箇所を一括置換。
- `border-mirai-gradient`（グラデ枠）は `border border-mirai-border bg-white` へ置換。
- BillCover（議案カバー）の6系統×3段階はグラデーションをやめ、DADS 各色相 50/100/200 のフラット単色に変更（カテゴリ識別の色相は維持）。
- stance（賛否）等の意味色も DADS green / red / yellow スケールへ調整。
- Lexend Giga フォントを廃止（`font-lexend` 使用箇所もなくなったため `layout.tsx` から読み込み削除）。

### 主要コンポーネント

- **Hero**: テラコッタのイラスト画像 → 薄青のフラット面＋見出し＋説明文。「powered by AI」表記と Scroll インジケーターを廃止。二本煙突モチーフは `public/img/hero-symbol.svg`（青系ゴースト調）として維持。
- **Header**: 浮きカード（top-4 + rounded-2xl + shadow） → 全幅白＋下罫線のフラットヘッダー。モバイルクイックナビは罫線チップ化。
- **Footer**: ピンクグラデ → 白＋上罫線。
- **Button**: default = `bg-primary text-white`、outline = `border-primary text-primary`。rounded-full と黒枠を廃止。
- **チャットUI**: 入力欄のグラデ枠丸チップ → 白地＋グレー罫線＋rounded-lg。送信/チャットアイコンSVGは青丸フラットに描き直し。
- **カード類**: `Card` の shadow を廃止し `rounded-lg border`。BillCard の黒枠 → `border-mirai-border`。「注目🔥」バッジ → 青ベタ「注目」バッジ。
- **Archive 系ページ**: ヒーロー画像・英字タイポを廃止し、日本語見出し＋薄青タイトルバンドに変更。

### ロゴ・アイコン・メタ情報

- `logo.svg` / `service-logo.svg` の二本煙突モチーフは維持し、青系（`#0017c1` / `#00118f`）へ再着色。
- `public/icons/` 配下のテラコッタ色SVGを青系へ一括置換。
- `manifest.json` の theme_color / background_color、`viewport.themeColor`、NextTopLoader の色を更新。
- OGP動的生成（`/api/og/bills/[billId]`・`/api/og/report`）の色定数を新トークン値へ同期。

## スコープ外（今後の課題）

- admin アプリのデザイン刷新（本PRは web のみ）。
- PWAアイコン（`public/icons/pwa/`）の再着色。
