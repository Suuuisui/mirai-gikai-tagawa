# トップページ編集の候補一覧に会期の絞り込みを付ける

## 背景

admin の「トップページ編集」（`/homepage`）で、最新の会期（令和8年（第6回）9月定例会）の議案を「注目の議案」に入れたいのに、候補一覧に出てこない問題があった。

原因は次の2点で、本番データ自体は正常だった（9月定例会の12議案・8月臨時会の5議案はすべて `publish_status = published`）。

1. 「追加できる議案」は興味度スコア順の上位20件しか表示しない。最新会期の議案は議決前で争点が無く（否決・反対討論などの加点が無い）スコアが低いため、626件の候補の中で20件に入らない
2. 検索は議案名・タイトル・タグ名にしか効かず、「9月定例会」「令和8年」のような会期名では探せない

タグ別セクションの「他の議案を固定する」候補も同じくスコア順のため、最新会期の議案は末尾に埋もれていた。

## 変更内容

### 注目の議案の候補（`featured-bills-editor.tsx`）

- 候補の上に「会期」セレクトを追加。選択肢は開会日の新しい順で、アクティブな会期には「（アクティブ）」を添える（議案一覧の会期セレクトと同じ表記）
- 初期状態はアクティブな会期に絞る（「今の会期の議案をトップに出す」が主な用途のため）。アクティブな会期が無い、または公開議案が無い場合は「すべての会期」
- 会期で絞り込んだときは20件の表示上限を掛けない（1会期分は多くても数十件）
- 検索キーワードは会期名にも一致する

### タグ枠の固定候補（`tag-pin-editor.tsx`）

- 「他の議案を固定する」を開いた中に同じ「会期」セレクトを追加（初期値は「すべての会期」。ボタンの件数表示と一致させるため）
- 該当が無い会期を選んだときは「すべての会期」に戻す案内を出す

### 共通化

- `admin/src/features/diet-sessions/client/components/diet-session-filter-select.tsx`: 会期セレクト本体（「すべての会期」を null で親に渡す）。議案一覧の `BillSessionFilter` はこれに URL 同期を被せるだけになった
- `admin/src/features/diet-sessions/shared/utils/build-diet-session-filter-options.ts`: 選択肢を組み立てる純粋関数（テスト付き）。`ALL_DIET_SESSIONS` 定数と `DietSessionFilterSource` 型は diet-sessions 機能側へ移した
- `admin/src/features/homepage/shared/utils/filter-candidate-bills.ts`: 候補を会期ID・キーワードで絞り込む純粋関数（テスト付き）
- `CurationBill` に `sessionId` を追加し、`HomepageData.dietSessions`（公開議案がある会期のみ、新しい順）を loader で組み立てる

## 確認したこと

- `pnpm --filter admin typecheck` / `pnpm --filter admin test` / Biome
- ローカル Supabase（最新会期を含むシードデータ）で admin を起動し、375px・1280px で `/homepage` を Playwright で撮影。横はみ出し・コンソールエラーなし
  - 初期表示でアクティブな会期（9月定例会）の12議案が候補に並ぶ
  - タグ枠「予算」の固定候補を9月定例会に絞ると補正予算5件が出る。「決議」「決算」など該当が無いタグでは案内文が出る

## 運用メモ

- 会期の絞り込みは画面内の状態で、URL には残らない（保存で画面が再読込されると初期状態＝アクティブな会期に戻る）
- 「アクティブな会期」は会期管理画面のフラグ（`diet_sessions.is_active`）。最新会期を取り込んだら `scripts/upsert-sessions.mjs` が1件に保つ
