# 委員会記録に見出しとトピックを持たせる

## 背景

`/committees` に146会議を公開したが、「何もわからない・見にくい」という
フィードバックが続いていた。委員会ごとのグループ化と用語解説は入れたものの、
残っていた問題は次の2つ。

1. **会議を識別する手がかりが日付しかない**。一覧には要約の冒頭2行が出ていたが、
   どの回も「令和8年◯月◯日の◯◯委員会では…」で始まるため、拾い読みができない
2. **委員会名でしか探せない**。「コミュニティバスの話がどこにあるか」を知るには、
   建設経済委員会の記録を1件ずつ開くしかなかった

委員会名（総務文教・厚生・建設経済…）は所管の区分であって、市民が知りたい
「何の話か」とは一致しない。同じテーマが複数の委員会にまたがることも多い。

## 追加したデータ

`committee_meetings` に2列追加（マイグレーション:
`20260902090000_add_headline_topics_to_committee_meetings.sql`）。

| 列 | 内容 |
| --- | --- |
| `headline` | その会議で一番中身のあることを表す見出し。18〜28字の体言止め |
| `topics` | 暮らしのテーマのid配列（1会議あたり1〜3個） |

### トピックの語彙

`web/src/features/committees/shared/data/committee-topics.ts` に12種を固定で定義する。
AIに自由に付けさせるとブレて入口として機能しないため、語彙は必ずここから選ぶ。

`money`（お金の使い道）/ `welfare`（福祉・子育て）/ `education`（学校・教育）/
`waste`（ごみ・環境）/ `transport`（交通・道路）/ `city`（まちづくり・住まい）/
`health`（医療・健康）/ `industry`（産業・仕事）/ `safety`（防災・安全）/
`cityhall`（市役所の仕事）/ `assembly`（議会のしくみ）/ `investigation`（疑惑の調査）

ラベルは変えてよいが**idは変えない**こと（既存データの付け直しが必要になる）。

### 見出しの書き方

- 会議名・日付は入れない（別に表示される）
- 「〜について」「〜の件」のような中身の無い表現は禁止
- 数字が効く場合は入れる（例:「市立病院の赤字2億8千万円を報告」）
- 議事日程の確認だけの回も、何を決める議会だったのかが分かるように書く
- 複数の議題があるときは市民の関心が高いものを選ぶ（お金・暮らし・不正 > 手続き）

## 表示

### 一覧 `/committees`

- **気になるテーマから探す**: トピックのボタン（件数付き）。選ぶと委員会をまたいで
  該当する会議を新しい順に並べる。絞り込みはClient Componentのstateで持つ
- **最近の会議**: 直近6件を見出しで見せる
- **委員会別**: 従来どおり常任→特別→その他。各会議の行は
  「見出し／日付・出典」の2段に変更（要約の抜粋はやめた）
- 委員会カードの初期表示を5件→3件に減らした

RSCのペイロードを抑えるため、Client Componentへ渡すのは `CommitteeMeetingListItem`
（id・委員会名・日付・見出し・トピック・出典）だけにする。要約と要点は渡さない。

### 詳細 `/committees/[id]`

- h1を見出しに変更（従来は「2026.1.15 の会議」）。委員会名と日付は上の行へ
- トピックのバッジを出典バッジの隣に表示
- `<title>` も「{見出し}｜田川市議会 {委員会名}」に変更。検索結果で中身が伝わる

## 生成の手順

1. `committee-work/enrich/in/` に会議を1件1ファイルで分割
2. Claudeのサブエージェント（1体あたり24件）に
   `committee-work/enrich/PROMPT.md` を渡して処理させる。**1件ごとにファイルを
   書き出させる**（セッション制限で落ちても進捗が残る）
3. `headline` / `topics` の付与と同時に、原文と突き合わせて要約の事実誤りも直す
4. `scripts/import-committee-meetings.mjs` で upsert

PROMPT.md には議員名簿（18名）・市長・自動字幕の誤変換対応表を載せてある。
名簿が更新されたらここも更新すること。

### 見つかった要約の誤り

初回生成時の要約には、原文に無い数字や固有名詞が混じっていた。主な例:

- 原文に無い金額・施設名の付加（繰越明許費の額、投票所の変更先、学力調査の結果）
- 「B工区」を「B校区」と取り違え
- 開示文書に根拠の記載が無いのに「百条委員会」と断定
- 自動字幕から確定できない商品券の名称を、それらしい名前で補完

いずれも原文と1件ずつ突き合わせて削除・修正した。**原文から読み取れないことは
書かない**方針を、生成プロンプトに明記している。
