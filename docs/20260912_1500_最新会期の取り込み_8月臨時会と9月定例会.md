# 最新会期の取り込み: 令和8年8月臨時会と9月定例会（会期中）

## 目的

浦野新市長の就任後の議会（8月10日の臨時会、9月7日開会の定例会）を、なるべく
精度高くサイトに反映する。会期中の定例会は議決結果ページがまだ無いため、
公式の「提出議案」ページと本会議の中継映像を使って「審議中」として載せる。

## 取り込んだもの

### 議案（bills）

| 会期 | 出典 | 状態 |
| --- | --- | --- |
| 令和8年（第5回）8月臨時会（8/10） | 公式「提出議案と議決結果」ページ（scrape.ts で取り込み） | 5議案・結果確定 |
| 令和8年（第6回）9月定例会（9/7〜10/8） | 公式「提出議案」ページ + 本会議中継（9/7）| 12議案・11件は審議中 |

- 会期中の会期は `packages/seed/tagawa/data/ongoing-sessions.json` に手で置く。
  `build-csv.ts` が `sessions.json` と結合し、`resultLabel: null` + `statusNote` の議案を
  `status: introduced` / `status_note: 審議中（9月29日の本会議で採決予定）` として出力する。
  閉会して議決結果ページが公開されたら `tagawa:scrape` で `sessions.json` に取り込み、
  `ongoing-sessions.json` から消す（残っていると key 重複で build-csv がエラーになる）
- 9月定例会の決算認定議案（6件）と人事議案（3件）は 9/29 以降に上程されるため未収録。
  上程後に `ongoing-sessions.json` へ追記する
- 解説文は `bill-descriptions-batch-e.ts`（8月臨時会）と `bill-descriptions-batch-f.ts`
  （9月定例会）。典拠は新設した `source: "broadcast"`（議案説明資料PDF + 公式YouTubeの
  本会議中継の自動字幕）。会議録検索システムに本会議録が載るまでの暫定で、載ったら
  `minutes` に差し替えて質疑・討論を会議録で照合する
- 議員提出議案第62号（政治倫理条例検討特別委員会の設置）は 9/7 に可決済み。結果の
  出典として `resultSource: "broadcast"` を追加した
- 副市長の選任（議案第49号）は無記名投票（賛成13・反対4）のため、
  `vote-disclosure.ts` の無記名投票リストに追加し「全会一致」表示にならないようにした

## 直したもの

- `scrape.ts`: 公式の一覧ページから外れた古い会期（令和元年12月定例会）が
  再実行で消えていたため、前回の出力に残っている会期は引き継ぐようにした
- `build-csv.ts`: 会期一覧で強調する会期（`is_active`）を手で指定する定数をやめ、
  開会日が最新の会期を自動で選ぶようにした。会期の結合・強調会期の選択・状態表記・
  出典セクションの組み立ては `session-data-utils.ts` に純粋関数として切り出し、
  `session-data-utils.test.ts` で守る。解説文のキーが議案に一致しないときは warn する
- 議員提出議案第62号の提出者は説明資料PDFが未公開のため `bill-sponsors-data.ts` には
  載せていない（表示側の出典表記がPDF固定のため）。PDF公開後に転記する
- 会期まとめの注記「継続審議など、上記以外の結果」→「審議中・継続審議など、上記以外の議案」

## 本番への反映手順

1. `pnpm --filter @mirai-gikai/seed tagawa:build-csv` で CSV を生成
2. `seed:csv` は全消去するため本番では使わない。`scripts/upsert-sessions.mjs`
   （生成CSVから指定 slug の diet_sessions / tags / bills / bill_contents / bills_tags を
   差分投入。tags は無い行だけ挿入、既存の bills は admin 管理列を上書きしない、
   強調会期 is_active は1件だけになるよう他の会期の true を落とす）を本番の環境変数で
   `r8-5-rinji r8-6-teirei` を指定して実行
   ```bash
   npx dotenv-cli -e <本番env> -- node scripts/upsert-sessions.mjs r8-5-rinji r8-6-teirei
   ```
3. 委員会記録は `scripts/import-committee-meetings.mjs` に `committee-work/import-enriched.json`
   （8件を追記済み）を渡して upsert。`committee-work/` はリポジトリの外
   （`shigikai_市議会見える化/committee-work`、worktree から見て `../committee-work`）にある
   作業ディレクトリで、字幕の生データと要約の中間ファイルを置いている
4. `/api/revalidate` で `bills` `diet-sessions` `committee-meetings` のタグを再検証
